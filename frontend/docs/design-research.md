# Design and interaction research

Research date: 8 October 2026.

- Next.js App Router conventions and TypeScript setup: https://nextjs.org/docs/app/getting-started/installation
- W3C form notifications: https://www.w3.org/WAI/tutorials/forms/notifications/
- W3C error identification: https://www.w3.org/WAI/WCAG22/Understanding/error-identification
- Carbon file uploader: https://v10.carbondesignsystem.com/components/file-uploader/usage/
- Transkribus evidence-linked editing prior art: https://www.transkribus.org/editor

Applied decisions: explicit required fields; visible accepted file types and limits; equivalent browse and drag/drop intake; textual errors; native dialog semantics; keyboard focus styles; original image and transcript shown together; review decisions recorded; status names instead of color-only meaning; clear local-data and demo boundaries.

Visual direction: a calm document-review product, warm neutral source canvas, forest-green navigation/actions, serif editorial headings, restrained amber uncertainty states. No invented performance claims or fabricated benchmark dashboard. Evaluation metrics remain empty until real data exists.

The product's proposed technical differentiator is tested context sensitivity and selective rereading. Confidence displays and correction interfaces are established prior art, not a novelty claim.
